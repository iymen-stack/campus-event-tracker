# Campus Event Tracker

Campus Event Tracker is a CSC 443 Software Engineering project designed to help Augsburg University students discover campus events.

## Team

- Iymen
- Samson Gyasi
- Abshir

## Project Goal

The goal of the Campus Event Tracker is to provide a centralized place where Augsburg students can find events happening on campus.

Planned event types may include:

- Career fairs
- Sporting events
- Campus activities
- School performances
- Student organization events

## Planned Features

- Browse campus events
- Search and filter events
- Create events
- Delete events
